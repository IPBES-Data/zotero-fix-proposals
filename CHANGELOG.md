# Changelog

## 0.1.8

- Downloads and updates through the IPBES Literature Report website.
- Options of an item: their description (e.g. the work found) is shown where
  the title is, with room for it; more room for "Why".

## 0.1.7

- The window's styles are loaded with the version in the address, so that an
  update shows without restarting Zotero.

## 0.1.6

- While a group loads, the tabs show "Loading …" instead of the previous group.

## 0.1.5

- Tabs wait for a group which is still loading (the Status tab could show the
  previous group).
- Nothing can be sent for groups you cannot edit (buttons greyed out).
- Layout: more room for the change, links on one line, drop-down lists as wide
  as their contents, background to the bottom of the window.

## 0.1.4

- Safe Edit's checks of a batch (automatic sync, backup age) are asked for each
  time a fix is shown, and the Status tab refreshes them when opened: before,
  a message like "automatic sync is on" stayed after it was fixed.

## 0.1.3

- After *Make a backup* the proposals are checked again: before, the Fixes tab
  kept showing "backup too old" from the earlier check.

## 0.1.2

- Drop-down menus with a background: Zotero's basic styles (global.css) are
  loaded; without them the menu was transparent and drawn over the window.

## 0.1.1

- Drop-down lists (group, fix, backup) as Zotero menus: HTML lists did not open
  in the window and were drawn over it.

## 0.1.0

- First version: window with Status, Fixes, Undo and Restore; proposals from
  a web address or a local folder; changes only through Zotero Safe Edit
  (0.2.0 or newer).
